# configs

Application-level settings (INI + ALT pickle). Do not commit secrets. Paths are created automatically when saving.

| File | Purpose |
|------|---------|
| `config.ini` | FishVision video/RTSP GUI |
| `config_FVT.ini` | FishVision Trainer default template (shipped with repo) |
| `config_FVT_last.ini` | Last training session (auto-written on exit; local, not required in git) |
| `config_auto.ini` | Auto-label related |
| `ALT_Settings.pkl` | ALT window state (local) |
